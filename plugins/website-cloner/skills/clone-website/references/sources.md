## Practitioner evidence (Reddit, read through the owner's armed tab on 2026-09-05)

- r/AI_Agents, author of an open-source clone tool: "Screenshots can actually mess you up … work from the actual page structure: final size, position and style of every element"; "fonts, SVGs and images silently mess up your layout — pull the actual assets"; "clone to plain HTML first, then convert — two simple steps beat one hard one". Matches the design here (computed values, real assets, HTML-first). A commenter suggested Figma via an html2design extension + Codex as an alternate route.
- r/ClaudeAI on Playwright MCP: "avoid MCPs unless you absolutely need them — they bloat everything and are extremely slow; the CLI approach is faster, more reliable, more transparent"; another: "removed Playwright MCP due to context issues"; Chrome DevTools MCP is "better if you're digging into what's happening under the hood", Playwright "smoother for full test runs"; Claude in Chrome (`claude --chrome`) for a real session. Supports: scripts for the heavy lifting, a browser tool only for the sweep.
- r/webdev, author of a DOM-capture extension: compiled HTML is "100K+ tokens"; cleaning computed styles "down to ~5K" is what makes it usable. Supports: per-section specs with non-default, non-inherited properties only.
- r/DigitalMarketing thread: a commenter recommends adding the Firecrawl MCP to "scrape a lot of the backend code" — a marketing claim; Firecrawl returns rendered HTML/markdown, nothing a headless browser does not already see. Not adopted. Another: "still takes work … especially for responsive design"; one practitioner emits a JSON per section for a page-builder template so "each section is editable" — supports per-section outputs.
- Commercial tools seen in search (CopyWeb, Alloy, uxmagic, aidesigner) claim 95–99 % but publish no method; not evidence.

## Measured here, 2026-09-05

- playwright.dev: 4 sections, 3 breakpoints, 42 hover samples. Snapshot fast path scored 100 % on every section, 0 % slice mismatch. A damaged copy (hero background, footer column removed, h1 48 px) was caught: hero 10.75 %, footer 30.58 %, element delta `h1 size 60px→48px`.
- astro.build: 12 sections, tabs×11, accordion×3. Snapshot scored 10/12 at 1440; the two failures (themes carousel, support block) are JS-hydrated state the stripped snapshot cannot carry, and `check.js` failed 10 of 11 tab contracts as INERT — the gate working as designed.
